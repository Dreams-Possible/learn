# Web 技术入门

## 1. Web 是什么

Web（World Wide Web，万维网）是建立在互联网之上的信息与应用系统。我们通过浏览器访问网页、点击链接、填写表单，都是在使用 Web。互联网是网络基础设施，Web 是使用这套设施的一种服务；电子邮件等服务也使用互联网。

几个常用概念：

| 概念 | 入门理解 |
| --- | --- |
| 网页 | 浏览器展示的一份文档，可以包含文字、图片、链接和交互 |
| 网站 | 由一组相关网页和资源组成的整体 |
| 浏览器 / 客户端 | 请求资源、解析内容，并提供交互环境，例如 Chrome、Edge、Firefox |
| 服务器 | 接收请求并返回网页、文件或数据的程序，也常指运行这些程序的计算机 |
| URL | 资源的地址，例如 `https://example.com/notes?topic=html#intro` |
| HTTP / HTTPS | 浏览器与服务器交换请求和响应的协议；HTTPS 使用 TLS 加密传输 |
| 域名 / DNS | 域名便于人记忆；DNS 帮助客户端查找域名对应的网络地址 |

上面的 URL 中，`https` 是协议，`example.com` 是主机名，`/notes` 是路径，`?topic=html` 是查询参数，`#intro` 是片段标识。片段通常用于页面内定位，不会随 HTTP 请求发送给服务器。

## 2. 打开一个网页时发生什么

以首次访问一个普通网站为例，可以先这样理解：

1. 浏览器根据 URL 确定要访问的资源，并通过 DNS 等机制获得服务器地址。
2. 浏览器建立连接；访问 HTTPS 时，还需要建立安全通信。
3. 浏览器发送 HTTP 请求，服务器返回响应，例如 HTML 文档。
4. 浏览器解析 HTML，发现 CSS、JavaScript、图片等引用后，再加载相关资源。
5. 浏览器根据页面结构与样式计算布局、绘制页面；JavaScript 可以响应操作并修改页面。

这是简化过程。缓存可能省去部分网络请求，脚本的加载方式也会影响执行时机。排查具体页面时，以开发者工具中的实际请求为准。

## 3. 前端、后端与三门基础技术

**前端**主要负责浏览器里呈现的内容、视觉和交互；**后端**主要负责服务器上的业务处理、身份校验和数据读写。数据库通常由后端访问。前端可以通过 HTTP API 获取后端返回的数据，例如 JSON。

| 技术 | 全称 | 负责什么 | 例子 |
| --- | --- | --- | --- |
| HTML | HyperText Markup Language，超文本标记语言 | 内容、结构和语义 | 标题、段落、按钮、表单 |
| CSS | Cascading Style Sheets，层叠样式表 | 外观、布局和适配 | 字体、颜色、间距、Flex 布局 |
| JavaScript | JavaScript，常简称 JS | 程序逻辑和交互 | 点击计数、输入检查、更新内容 |

例如一个“记录学习次数”的按钮：HTML 创建按钮和结果区域，CSS 控制外观，JavaScript 在点击后增加次数。

静态网页可以直接由服务器提供文件，不一定需要自建后端。JavaScript 也可以运行在 Node.js 等浏览器以外的环境中，因此它的用途不局限于前端。

## 4. 三种文件怎么配合

`HTML/index.html` 通过 `link` 引入 `CSS/style.css`，通过 `script` 引入 `JavaScript/main.js`：结构引用样式和脚本，三者共同组成页面。

用浏览器直接打开 [HTML/index.html](HTML/index.html)，就能看到页面。点击“记录一次学习”，次数会增加；点击“重置”，恢复为 0。这个例子只保存在页面内存中，刷新后次数归零。

不需要安装框架或构建工具。这里为了对应学习目录，把三种文件分开放置；实际项目可以按功能组织文件，不必照搬这个结构。

## 5. 入门调试方法

浏览器按 `F12`，或通过浏览器菜单打开开发者工具：

- **Elements / 元素**：看 HTML 解析后的结构，临时修改 CSS，查看实际生效的样式。
- **Console / 控制台**：执行 JavaScript，查看 `console.log()` 输出和报错。
- **Network / 网络**：查看资源请求、HTTP 状态码和返回内容。直接用 `file://` 打开文件时，不会产生普通网页服务器的 HTTP 响应状态码。

开发者工具里的临时修改通常不会保存回源文件，确认效果后还要修改仓库中的文件。

遇到问题先检查：文件路径与大小写是否正确、文件是否保存、控制台有没有报错、CSS 是否被覆盖。等后续学习 `fetch`、模块脚本等能力时，再使用本地 HTTP 服务，避免直接打开文件的限制。
