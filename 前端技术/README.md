# 前端技术：Vite、React 与 Vue

## 1. 三者分别负责什么

HTML、CSS、JavaScript 是网页的基础。页面复杂后，可以用组件组织界面，用构建工具处理项目文件和开发流程。

| 技术 | 定位 | 主要解决什么 | 不负责什么 |
| --- | --- | --- | --- |
| Vite | 前端开发与构建工具 | 启动开发服务器、处理源码、生成可部署文件 | 不规定按钮、页面组件怎么编写 |
| React | 用于构建用户界面的 JavaScript 库 | 用组件描述界面，根据状态更新显示 | 核心库不包办构建、路由、后端等全部能力 |
| Vue | 渐进式 JavaScript 框架 | 用模板、组件和响应式数据组织界面 | 不会自动提供业务后端或数据库 |

**Vite 与 React / Vue 是配合关系；React 与 Vue 通常是同一层面的不同选择。** 常见组合是 Vite + React，或者 Vite + Vue。Vite 也能用于普通 JavaScript 项目，React、Vue 也不只支持 Vite。

## 2. 从直接操作页面到组件

原生 JavaScript 通常自己完成：找到元素 → 监听事件 → 修改数据 → 把新内容写回 DOM。

React、Vue 中通常是：用组件声明“界面随数据如何显示” → 事件修改状态 → 框架根据状态更新界面。

| 概念 | 含义 | 例子 |
| --- | --- | --- |
| 组件 | 把一块界面及其逻辑封装成可组合、可复用的单元 | 一个计数器、一个搜索栏、一张商品卡片 |
| 状态 | 组件记住、且可能影响显示的数据 | 当前次数 `count` |
| 渲染 | 根据组件描述和当前数据生成、更新界面 | 把当前次数显示成文字 |
| props | 父组件传给子组件的输入 | 给计数器传一个标题 |
| 声明式写法 | 描述数据与显示的关系，由框架处理具体 DOM 更新 | 声明“这里显示 count”，再通过状态 API 改变 count |

组件不会自动拥有特别的外观，颜色、间距、布局仍由 CSS 决定。两种框架中的具体语法不同，但组件化和数据驱动界面的思路相通。

## 3. 项目从源码到浏览器

```text
开发时：组件源码 → Vite 开发服务器处理 → 浏览器加载页面
发布时：组件源码 → 构建命令 → dist 目录 → 部署到网站服务器
```

浏览器最终运行的仍是 HTML、CSS、JavaScript。JSX、`.vue` 等写法需要工具转换，不能把它们当作普通 HTML 直接双击运行。

Node.js 为本地工具提供 JavaScript 运行环境，npm 用来管理依赖和执行项目脚本；它们与浏览器中运行的页面是不同环节。开发工具使用 Node.js，并不代表网站必须有一个 Node.js 业务后端。
